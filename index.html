Ph.D. Student in Computer Science · University of California, Riverside

I study the security of GPUs and memory systems. My work finds new ways that hardware features — page migration, Rowhammer mitigations, multi-GPU interconnects — can be turned against the isolation they are meant to provide, and designs defenses that cost less. I am advised by Prof. Nael Abu-Ghazaleh.

Research

Hardware security and computer architecture, with a focus on GPUs, DRAM, and heterogeneous memory systems. Findings are responsibly disclosed to the affected vendors, and attack code is released on GitHub.

PAGE404 · IEEE S&P 2027

GPU isolation on the NVIDIA GH200

Hardware-assisted page migration in GPUs can be abused to break MIG isolation between co-located workloads.

Not so Refreshing · USENIX Security 2025

Rowhammer mitigations as attack vectors

The DRAM Refresh Management (RFM) mitigation itself can be exploited to attack GPUs.

NVBleed · ACM CCS 2026 · SEED 2024

Multi-GPU interconnect channels

Contention-based covert and side-channel attacks on the NVIDIA NVLink interconnect.

PRACtical · under submission

Efficient Rowhammer defense

Subarray-level counter updates and bank-level recovery isolation cut PRAC's performance overhead, evaluated in Ramulator.
